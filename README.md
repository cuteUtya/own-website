# Tymur Tereshchenko — Engineering Consultancy

A static, accessible Next.js portfolio and B2B services website.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
```

The static site is generated in `out/`.

### Vercel

Import the repository in Vercel and deploy with the detected Next.js settings.
Add the production domain under **Project Settings → Domains**.

### GitHub Pages

The included workflow deploys `out/` whenever `main` is updated. In the
repository settings, select **GitHub Actions** as the Pages source. Add a custom
domain in **Settings → Pages** if needed.
